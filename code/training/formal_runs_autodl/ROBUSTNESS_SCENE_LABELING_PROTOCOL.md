# Pretrained-SGD 鲁棒性评价：人工场景标注协议

## 固定样本集

使用正式 `source_disjoint_v1` 的 1555 张验证图像。官方 test 没有公开标签，不能计算本任务要求的 mAP50-95 和 APsmall，因此不替换或混用其他测试集。

## 四类互斥标签

- `Normal`：没有明显影响可见性的强反光，也没有全局低照度。
- `Glare`：水面或镜头中存在明显局部高亮、反射光带或太阳眩光，可能淹没目标细节；整幅图并非明显低照度。
- `Low-light`：全图明显偏暗、欠曝光或接近黄昏/夜间，暗部细节受损；没有同时出现主导性的强反光。
- `Mixed`：同一图像同时满足明显低照度和明显反光两个条件。

标签描述当前原始图像的可见场景，不参考模型预测结果，也不根据目标是否检测成功反推标签。

## 审阅流程

1. 脚本从原始 COCO metadata 恢复每张验证图像的采集视频/采集文件夹。
2. 先审阅每个 source group 的均匀抽样总览，再逐页审阅该组全部图像。
3. 仅当整组视觉条件稳定时才使用 group-level 标签；任何发生变化的帧都写入 image override。
4. 图像统计量和 heuristic label 只用于排序和提示，不能作为最终标签。
5. 决策文件必须覆盖 1555 张图像；脚本拒绝缺失、重复或非法标签。
6. 最终保存 group 决策、image override、逐图 CSV、联系表和 SHA-256，以便复核。
